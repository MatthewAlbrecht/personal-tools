Backend sync (optional)

Default targets production. For local Convex/dev server, set origin to http://127.0.0.1:1333. Use the same secret as RYM_EXTENSION_INGEST_SECRET in the deployed app env. Scrapes still save locally without a secret.

The same origin and ingest secret also power the Bandcamp album capture button.

Automated captures

Turn this on only in the Chrome profile the Yu-Gi-Oh automation script opens. While it's on, this profile checks the tracker every minute for a run the script asked for, then opens every Search and TCGplayer page in its own window. See docs/yugioh/automation.md.
